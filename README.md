# Mohammed's  Web Portfolio 🚀

**Live Demo:** [https://mohammed054.github.io/portfolio/](https://mohammed054.github.io/portfolio/) 

Hey there! I'm **Mohammed**, a self-taught web developer who loves turning complex problems into simple, beautiful, and interactive solutions. This isn't just a portfolio—it's a playground of code where pixels meet personality.

What started as high school tinkering has evolved into a passion for creating web experiences that are as fun to use as they are to build. When I'm not debugging (which is most of the time), you'll find me playing retro games or experimenting with the latest web technologies.

---

## ✨ Ultra Portfolio Features

### 🎮 Interactive Elements
- **Snake Game Terminal**: Full playable Snake game in a retro terminal window
- **Rocket Launch Animation**: Click the rocket for an explosive launch sequence with particles
- **Draggable Windows**: Move, minimize, and maximize the game terminal
- **Sound Effects**: Web Audio API-powered game sounds and rocket effects

### 🎨 Human-Touch Design
- **Handwritten Fonts**: Organic, imperfect typography using Google Fonts' Kalam
- **Subtle Imperfections**: Cards with slight rotations and offsets for natural feel
- **Conversational Copy**: Real talk instead of corporate speak
- **Interactive Animations**: Smooth, organic transitions that feel alive

### 📱 Complete Sections
- **About**: Personal story with authentic anecdotes
- **Skills**: Technical abilities with learning roadmap
- **Experience Timeline**: Journey from beginner to developer
- **Projects**: Embedded live demos of actual work
- **Blog**: Latest thoughts and insights (ready for content)
- **Contact**: Multiple ways to connect with social links

### 🛠️ Technical Excellence
- **Responsive Design**: Perfect on desktop, tablet, and mobile
- **Accessibility**: WCAG-compliant with semantic HTML
- **Performance**: Optimized loading and smooth animations
- **SEO Ready**: Proper meta tags and semantic structure

## 🛠️ Technologies Used

- **HTML5** - Semantic structure and accessibility
- **CSS3** - Advanced layouts, animations, and responsive design
- **JavaScript (ES6+)** - Interactive features and game logic
- **Web Audio API** - Sound effects and audio manipulation
- **Google Fonts** - Inter, Space Grotesk, and Kalam for typography
- **CSS Grid & Flexbox** - Modern layout techniques

## 🚀 Quick Start

1. **Clone & Navigate**:
   ```bash
   git clone https://github.com/mohammed054/portfolio.git
   cd portfolio
   ```

2. **Serve Locally**:
   ```bash
   python -m http.server 8000
   ```

3. **Open Browser**:
   Visit `http://localhost:8000` to see the magic happen!
