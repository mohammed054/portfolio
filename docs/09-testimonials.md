🌟 Testimonials / Wall of Trust

Concept: Calm, confident, editorial-style layout. No orbiting chaos — think NYT review page, professional and minimal, yet subtle 3D depth.

1. Layout

Desktop: Featured quote center, supporting quotes flanking sides

Mobile: Vertical stacked cards, swipeable

Background: Slow-moving depth layers (parallax only, minimal)

Typography: Syne for names / roles, DM Sans for quotes

2. Card Structure
┌──────────────────────────────────┐
│  "Mohammed built an outstanding  │
│   school management platform —  │
│   efficient, intuitive, and AI- │
│   powered. Highly recommended." │
│                                  │
│  ● Sara Al-Mansoor · Principal  │
│    [LinkedIn →]                 │
└──────────────────────────────────┘

Rules:

Max 2–3 sentences per quote

Prefer metric-driven praise, not generic “great work”

Subtle accent color on name / role

3. Interactions
Action	Effect
Entry	Cards stagger in from bottom (80px offset, 300ms, eased)
Hover	Subtle 2px Y lift, border brightens slightly
Click	Expand quote → optional modal with full feedback
Scroll	Parallax depth layers move slowly, text stays readable
4. 3D Elements (Subtle)

Depth layers behind cards → Z-axis movement only, no spinning / orbiting

Optional 3D extruded quote marks as decorative elements

Minimal particle interaction if cursor moves (very subtle)

5. Accessibility

All quotes text-based → readable by screen readers

ALT text for any supporting images / avatars

Focusable cards with keyboard navigation
