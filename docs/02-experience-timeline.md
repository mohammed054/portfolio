# 02 — EXPERIENCE TIMELINE

**Role:** Defines what happens across the full 0 → 1 progression
**Depends on:** 00-masterblueprint.md, 01-camera-system.md

---

# 1. CORE MODEL

The entire experience is driven by a single value:

```js
progress ∈ [0, 1]
```

Everything maps to this:

* camera position
* scene activation
* object visibility
* interaction intensity
* lighting
* sound

---

# 2. GLOBAL STRUCTURE

| Phase      | Range       | Purpose         |
| ---------- | ----------- | --------------- |
| Entry      | 0.00 – 0.15 | Curiosity       |
| Authority  | 0.15 – 0.30 | Identity        |
| Capability | 0.30 – 0.50 | System Thinking |
| Proof      | 0.50 – 0.75 | Work            |
| Climax     | 0.75 – 0.90 | Depth           |
| Outro      | 0.90 – 1.00 | Release         |

# 3. TIMELINE BREAKDOWN (PRECISE)

---

## 🟣 0.00 — 0.05 → VOID ENTRY

### Environment

* near-black space
* very subtle noise / gradient

### Objects

* barely visible floating particles
* low density

### Interaction

* mouse → slight parallax only

### Purpose

* disorientation
* curiosity trigger

---

## 🔵 0.05 — 0.15 → SYSTEM EMERGENCE

### Environment

* depth becomes visible
* faint light sources appear

### Objects

* floating geometric elements (cubes / panels)
* slow independent motion

### Interaction

* hover → slight magnetic attraction
* objects respond softly

### Transition Trigger

* density increases gradually

### Purpose

> “You are entering a system”

---

## 🔴 0.15 — 0.22 → AUTHORITY IMPACT

### Event

* camera pushes aggressively forward

### Objects

* MASSIVE typography appears in depth:

MOHAMMED HASSOUN
FULL STACK ENGINEER

* text is intersected by floating objects
* slight occlusion

### Interaction

* reduced (focus on impact)

### Purpose

* establish identity
* scale shock

---

## 🟠 0.22 — 0.30 → TYPOGRAPHY PASS-THROUGH

### Event

* camera moves THROUGH text

### Behavior

* letters act as spatial structures
* lighting shifts as camera crosses

### Transition

* text fades behind
* new space revealed ahead

### Purpose

* reinforce depth
* transition into system thinking

### Environment

### Camera

# 4. TRANSITION RULES

---

## Allowed Transitions

* zoom into object → becomes world
* object occludes → reveals next scene
* continuous forward movement

---

## Forbidden

* fades between scenes
* cuts
* UI-based transitions

---

# 5. DENSITY CONTROL

Density must follow:

```text
low → medium → high → medium → low
```

---

## Purpose

* avoid fatigue
* maintain clarity
* create rhythm

---

# 6. INTERACTION INTENSITY CURVE

| Phase      | Interaction |
| ---------- | ----------- |
| Entry      | very low    |
| Emergence  | low         |
| Authority  | minimal     |
| Capability | medium      |
| Proof      | controlled  |
| Climax     | minimal     |
| Outro      | high        |

---

# 7. FOCUS CONTROL

At ALL times:

* one primary object
* everything else supports it

---

## Implementation

* lighting isolates focus
* depth of field assists
* camera.lookAt enforces it

---

# 8. FINAL TIMELINE DEFINITION

This experience is:

> A continuous transformation of space, where objects emerge, evolve, and dissolve as the camera progresses through a controlled timeline, revealing identity, capability, and proof through spatial storytelling.

There are no sections.

Only:

> states of the world changing over time.
