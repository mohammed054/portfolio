The strongest current competitor language is clustered around concrete workflow outcomes rather than generic "software development":

- Document processing competitors lead with a specific manual pain, then promise structured JSON, validation, evaluation, pilot phases, integrations, and on-prem or controlled deployment where needed.

## Image Generation Direction

Use generated images for:

- Service OG images with abstract but concrete workflow diagrams
- Insight hero/OG images that explain a process visually
- Simple document-flow or browser-extension diagrams

Avoid generated images for:

- Fake app screenshots
- Invented client dashboards
- Photorealistic people using software
- Any image that implies unproven metrics, clients, or live production systems

Recommended output format:

- OG images: 1200x630 PNG or WebP
- Article diagrams: 1600x900 PNG or WebP
- Keep all final generated assets in the repository under a future `public/images/content/` or equivalent CMS import directory
