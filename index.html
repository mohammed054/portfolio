About Me

Hey! I'm Mohammed, and yeah, I'm a web developer. But let's be real—I'm that guy who spends way too much time tinkering with code, breaking stuff just to see if I can fix it (usually with coffee in hand). My coding journey started back in high school when I accidentally deleted my first website and had to rebuild it from scratch. Lesson learned: backups are important, but so is curiosity!

What drives me? Making the web a little more fun and accessible for everyone. I've got a soft spot for pixel art (as you can see from my rocket obsession) and retro games—my all-time favorite is Pac-Man, even though I still get eaten by ghosts half the time. When I'm not debugging or learning the latest JavaScript framework, you'll find me doodling UI ideas on napkins or debating whether tabs or spaces are superior (I use both, don't judge).

Oh, and I'm based in the UAE, which means my code has a bit of that desert heat in it—passionate, sometimes unpredictable, but always aiming for something awesome. Let's chat about your project—I promise I won't bore you with tech jargon unless you ask!

Task Dashboard

What it is

A responsive web application that serves as a personal task management dashboard, allowing users to create, organize, and track their daily tasks and activities.

Why it exists

Built to solve the common problem of scattered task management. Many people struggle with organizing their daily responsibilities across multiple devices and platforms, leading to forgotten tasks and decreased productivity.

Browser-Based OS System

What it is

A fully functional simulated operating system that runs entirely in the web browser, complete with a desktop interface, file system navigation, window management, and several built-in applications like a text editor and calculator.

Why it exists

Created to explore the limits of web technologies and demonstrate advanced JavaScript capabilities. It addresses the challenge of building complex, interactive desktop-like experiences within the constraints of browser environments, pushing the boundaries of what's possible with client-side code.

Tech used
  • HTML5 & CSS3 (Advanced CSS for window styling and animations)
  • JavaScript (ES6+ classes, event handling, DOM manipulation)
  • Canvas API for graphical elements
  • Local Storage for file system persistence
What I learned

Gained deep insights into complex DOM manipulation, event-driven architecture, and building modular JavaScript applications. Learned about window management systems, drag-and-drop interfaces, and the challenges of simulating OS-level functionality in a browser environment. Also improved skills in canvas rendering and state management for large-scale web applications.
