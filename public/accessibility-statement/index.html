Accessibility Statement

Shader Development Studio is committed to making this experience usable for as many people as possible. We aim to provide clear structure, keyboard-accessible navigation, meaningful link text, and reduced-motion support where available.

If you encounter a barrier while using this site, please contact us so we can improve it: hello@shader.se.

  • Keyboard focus is preserved for interactive controls and links.
  • Decorative 3D and visual flourishes are marked as non-essential where possible.
  • Motion-heavy moments are reduced when the system requests reduced motion.
